# 開発記録（24h Activity Log）

日次行動記録と予定表を一つにまとめたスマホ向けアプリの作成記録．
新しい記録は上に追記していく．

### 現時点の構成
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（約2400行．CSS・HTML・JSを1ファイルに同梱） |
| `manifest.json` | PWA設定（アイコン未設定） |
| `sw.js` | Service Worker（キャッシュ優先でオフライン対応） |
| `README.md` | 実装済み機能の一覧 |

- 画面は3つ：**ホーム**（`#home`），**記録**（`#record`），**データ**（`#data`）
- データは `localStorage` のキー `activity_logger_v1` に保存
  - `categories`：カテゴリ一覧（固定：睡眠／食事／入浴＋初期カテゴリ）
  - `days`：日付ごとの予定・行動記録
- 予定（schedule）と行動を `mode` で切り替えて別々に管理
- 円形24時間グラフはSVGで描画（`svgClock`）

### 気づいた課題
- **日付のずれ**：初期日付を `new Date().toISOString()` で決めているためUTC基準になり，日本時間の0時〜9時は前日の日付が選ばれる
- **更新が反映されない可能性**：`sw.js` はキャッシュ優先でキャッシュ名が `activity-log-v1` 固定のため，`index.html` を更新してもスマホ側で古い版が表示され続けることがある
- `manifest.json` にアイコンがないので，ホーム画面に追加したときの見た目が未整備
- Notion連携は未接続（認証情報をスマホ側に置かないための中継方法を検討中）
