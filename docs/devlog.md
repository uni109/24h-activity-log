# 開発記録（24h Activity Log）

新しい記録は上に追記していく．

## 2026-10-13　既知の不具合の修正

### やったこと
- **日付ずれの修正**（`index.html`）
  - ローカル日付で `YYYY-MM-DD` を作る `ymd()` と，日付を前後にずらす `shiftDate()` を追加
  - 初期日付・前日／翌日ボタンの `toISOString()`（UTC基準）をこれらに置き換え
  - 確認：1:30 JSTの場合，旧方式は `10-12`，新方式は `10-13`．月またぎ・年またぎ・うるう日も正しく動く
- **Service Workerの更新方針を変更**（`sw.js`）
  - キャッシュ優先 → **ネットワーク優先**（オフライン時だけキャッシュを使う）
  - キャッシュ名を `activity-log-v2` に上げ，有効化したときに古いキャッシュを削除
  - `skipWaiting` / `clients.claim` で新しい版にすぐ切り替える
  - 同じオリジンへのGETリクエストだけを扱う
- **アイコンの追加**（`icons/`，`manifest.json`，`index.html` の `<head>`）
  - 24時間リングをモチーフにしたPNG：192・512・maskable 512・iOS用180
  - iOSのホーム画面追加に必要な `apple-touch-icon` などのタグを追加
- **追加で見つけた不具合**：`index.html` の先頭に「```html」，末尾に「```」が混入していた（9/18の `cc11bf6` から）
  - 画面に文字が表示され，ページが互換モード（quirks mode）で描画されていた → 削除して標準モードに戻した

### 決めたこと
- Service Workerはネットワーク優先にする．アプリを更新したらスマホでもすぐ反映されることを優先した
- キャッシュするファイルを増減したら `sw.js` の `CACHE` の番号を上げる

## 2026-10-12　作成記録の開始・現状把握

### やったこと
- GitHubリポジトリ（uni109/24h-activity-log）をローカル `daily_log_app` にclone

### 現時点の構成
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（約2400行．CSS・HTML・JSを1ファイルに同梱） |
| `manifest.json` | PWA設定（アイコン未設定） |
| `sw.js` | Service Worker（キャッシュ優先でオフライン対応） |
| `README.md` | 実装済み機能の一覧 |

- 画面は3つ：**ホーム**（`#home`），**記録**（`#record`），**データ**（`#data`）
- データは `localStorage` のキー `activity_logger_v1` に保存
  - `categories`：カテゴリ一覧（固定：睡眠／食事／入浴＋初期カテゴリ）
  - `days`：日付ごとの予定・行動記録
- 予定（schedule）と行動を `mode` で切り替えて別々に管理
- 円形24時間グラフはSVGで描画（`svgClock`）

### 気づいた課題
- **日付のずれ**：初期日付を `new Date().toISOString()` で決めているためUTC基準になり，日本時間の0時〜9時は前日の日付が選ばれる
- **更新が反映されない可能性**：`sw.js` はキャッシュ優先でキャッシュ名が `activity-log-v1` 固定のため，`index.html` を更新してもスマホ側で古い版が表示され続けることがある
- `manifest.json` にアイコンがないので，ホーム画面に追加したときの見た目が未整備
- Notion連携は未接続（認証情報をスマホ側に置かないための中継方法を検討中）
