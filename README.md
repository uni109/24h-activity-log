# 24h Activity Log MVP

スマートフォン向けの24時間行動記録プロトタイプです．

## 現在実装しているもの
- 日付選択
- ホーム：予定／行動の円形24時間グラフ＋タイムライン
- 記録：円周ドラッグで時間帯入力
- 現在時刻から記録
- 予定と行動を分離
- 重複時の上書き確認
- 24時間未満の確定時警告
- 確定後の修正
- 固定カテゴリ：睡眠／食事／入浴
- 自由なカテゴリ追加・削除
- 確定時のMarkdown生成
- JSONバックアップ
- PWA用manifest／Service Worker

## 注意
このMVPではNotion APIへの送信処理はまだ接続していません．
Notionの認証情報をスマホ側コードに直接埋め込まないため，次段階で安全な中継方法を設計します．

## スマホで使う
PWAとしてインストールする場合は，HTTPSで配信してください．
単純な動作確認ならindex.htmlをブラウザで開いてUIを確認できます．
